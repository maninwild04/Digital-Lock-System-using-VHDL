# Digital Lock System Using VHDL

## Overview
A password-based digital lock system designed using VHDL
and Xilinx ISE.

## Features
- 4-bit password verification
- Clock-controlled operation
- Asynchronous reset
- Locked and unlocked status indicators

## Password
The predefined password is 1010.

## Inputs
- clk: Clock input
- rst: Asynchronous reset
- code_in: 4-bit password
- enter: Enter button

## Outputs
- lock_led: Indicates the locked state
- unlock_led: Indicates the unlocked state

## Tools Used
- Xilinx ISE
- VHDL
- RTL Schematic Design

## Design Screenshots
The repository includes RTL and technology schematics
generated in Xilinx ISE.

## Applications
- Electronic access control
- Digital security systems
- FPGA-based digital design
